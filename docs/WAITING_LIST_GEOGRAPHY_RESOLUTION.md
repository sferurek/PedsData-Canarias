# Listas de espera — semántica territorial

**Dictamen del desglose insular: HOLD.**

ISTAC define TERRITORIO como reference area y publica códigos oficiales de las siete islas. La operación describe población en listas de centros hospitalarios del SCS y el portal SCS publica por hospital. Ninguna nota auditada aclara si la isla corresponde a residencia, centro de atención, área de adscripción u otra asignación.

La comparación con hospitales aporta contexto, pero no define la dimensión. Se mantiene solo Canarias como stock administrativo en fecha de corte; no se denomina demora ni se cruza con residentes insulares.

Fuentes auditadas: operación ISTAC C00045A, metadatos 1.3 y publicación semestral SCS.
