# SIVAMIN — resolución del HOLD

**Dictamen: HOLD.** El visor público confirma series desde 2017 por CCAA y cohortes, pero su informe incrustado no renderiza una tabla exportable reproducible: el Report Server devuelve el contenedor y falla el cliente Power BI. No se obtuvo fichero con filtro Canarias, vacuna, cohorte, numerador, denominador y estado.

Los resúmenes estáticos hallados son estatales o provisionales; no se usan como Canarias. El propio Ministerio advierte que una publicación temporal de 2024 fue corregida y que los datos actuales son definitivos. Sin export congelable no se asigna licencia/checksum de datos ni se integra cobertura.

Se reevalúa cuando exista CSV/XLSX/API o un informe autonómico con denominadores. Nirsevimab seguirá separado de vacunación y requiere población elegible propia. Fuente: [SIVAMIN](https://pestadistico.inteligenciadegestion.sanidad.gob.es/publicoSNS/I/sivamin/sivamin).
