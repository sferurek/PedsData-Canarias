# UI polish V2

RC2 mantiene la arquitectura visual de RC1 y añade:

- navegación Accesibilidad, Entorno, Desigualdad, Islas y Método;
- selector de una capa principal: accesibilidad, renta, densidad infantil, PM10, PM2.5 o NO2;
- leyenda, unidad, periodo y fuente específicos por capa;
- estaciones como puntos, sin superficies interpoladas;
- estados COMPLETE, ESTIMATED, PARTIAL y NOT AVAILABLE;
- Pediatric Access Gap V2 con columnas sociales y territoriales activables;
- contexto en perfiles insulares y municipales.

Los controles son elementos nativos con foco visible. El mapa conserva loading, error y success; las capas sin observaciones aparecen deshabilitadas. La tabla y los perfiles ofrecen alternativa textual. En móvil, la barra se apila y las tablas conservan desplazamiento horizontal.
