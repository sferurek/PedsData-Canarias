# Métodos de series temporales

La Fase 8 publica 1.372 observaciones registradas para población asignada 0–14, pediatras AP, utilización SIAP, nacimientos, prematuridad, espera regional y hospitalización regional seleccionada.

Las series conservan la geografía y grupos originales. Las islas solo se comparan cuando la fuente publica isla. Espera y hospitalización permanecen regionales. Las tasas derivadas usan denominadores compatibles del mismo periodo y territorio. Las visualizaciones admitidas son línea, barras, small multiples, heatmap, slope y scatter; no se usa doble eje.
