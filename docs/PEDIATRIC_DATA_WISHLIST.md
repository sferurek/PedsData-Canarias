## Texto base de solicitud

Solicitamos información estadística agregada y reutilizable para el Observatorio Pediátrico de Canarias, con cobertura de El Hierro, La Gomera, La Palma, Tenerife, Gran Canaria, Fuerteventura y Lanzarote. Para el producto indicado, agradeceríamos fichero tabular o API, diccionario, unidades, grupos de edad originales, periodos disponibles, códigos territoriales y sus cambios, reglas de confidencialidad, licencia y calendario de actualización. Los valores no disponibles deben distinguirse de cero y de supresión. No solicitamos datos identificativos. Si no existe el cruce solicitado, agradeceríamos identificar el máximo nivel publicable y el procedimiento para acceso a agregados adicionales.

Añadir el renglón específico de la tabla y pedir resolución expresa de diferencias entre nomenclátores. Registrar fecha, interlocutor institucional, respuesta y evidencia, sin publicar datos personales de contacto innecesarios.
