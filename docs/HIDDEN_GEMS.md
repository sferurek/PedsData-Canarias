# Hidden Gems
Auditoría28/09/2026. Son oportunidades trazables, no endpoints secretos ni resultados admitidos. URL primaria en cada ID de la [matriz](NEW_DATA_SOURCES_MATRIX.md).

1. **SIAP más allá de plantilla (01).** El catálogo tiene consultas por profesional/lugar, personas distintas y frecuentación. E54086A_000004–11 son productos diferentes; _000005 descargado. No asociar edad del cubo medicina con Pediatría de otro cubo sin correspondencia.
2. **Espera en API, no solo PDF (02–03).** C00045A ofrece stock en consultas y cirugía; estado M conserva ausencia. Pediatría 12/2025 tiene fila para cada isla. La existencia de0 en El Hierro no equivale a ausencia de barreras.
3. **Anexo nirsevimab (07), p. 14.** El boletín IRA incluye inmunización por área además de vigilancia respiratoria. Tabla en imagen: necesita doble extracción/verificación. Anticuerpo monoclonal, no vacuna; dosis/campañas no tasas poblacionales.
4. **Cobertura centinela escondida en método (07), p. 8–9.** La muestra AP del informe se restringe a las islas capitalinas; IRAG se apoya en DoctorNegrín. No utilizarlo como hospitalización pediátrica representativa de7 islas.
5. **Memoria Lanzarote (17), p. 88/p. 142.** Actividad del servicio Pediatría y AP por unidades nombradas. No usar sus unidades como ZBS vigentes. No confundir ingreso urgente con episodio en Urgencias.
6. **Agendas de Pediatría (19).** GAPGC publica demora histórica operativa; complementa distancia geográfica, pero no mide el recorrido del paciente ni garantiza cita actual.
7. **BDCAP exportación documentada (05).** Manual2024 muestra filtros y exportExcel, con dispensación además de morbilidad. Conviene probar export oficial antes de scraping. ATC/edad/CCAA, no consumo por isla.
8. **SiVIRA sección de descargas (08).** Informe HTML202443 anuncia Excel. La apertura de la página superó el límite de tamaño del lector; archivo no descargado. Hallazgo de localización C, no API validada.
9. **Cribados como calidad asistencial (15–16).** Indicadores de proceso neonatal distintos de nacimientos/prematuridad ya integrados.
10. **GTFS y meteorología insular (47–48).** Cabildo/TITSA aportan ficheros estructurados. Mejoran Tenerife; no constituyen cobertura archipelágica ni tiempos clínicos interinsulares.
11. **SIOSE AR y SICA (43–44).** Descargas GIS útiles para contexto infantil. Un WMS solo renderiza, no garantiza geometrías reutilizables; priorizar descarga documentada. No se acreditó WFS sanitario vigente nuevo.
12. **Diccionario DGT como hallazgo negativo (31).** El fichero es de accidentes; no incorpora edad víctima. No construir una capa de accidentes pediátricos con ese archivo.
13. **Ahogamientos (30).** API edad/isla, pero isla de inscripción no accidente/residencia; etiqueta menor de 4 seguida de5–14 obliga aclaración.
14. **Fechas engañosas.** Metadatos actualizados2026 pueden alojar diagnóstico2017, demanda social2014 o programa clínico antiguo. Usar el periodo del contenido.

No se han encontrado credenciales ni usado APIs privadas. Las rutas antiguas/índices encontrados sirven para localizar documentos; no se afirma continuidad de un endpoint porque exista un enlace histórico.
