# UI de Fase 8

La navegación añade Evolución, Comparar, Explorar, Pregunta y Fuentes sin desplazar el mapa de la portada. El selector cartográfico mantiene una capa principal y muestra escala, periodo, unidad y clasificación. El explorador funciona sin Ask PedsData.

Todo card, tabla, gráfico, mapa y respuesta semántica muestra **Fuentes de este resultado**. `/fuentes` y `/indicadores` son accesibles desde la navegación. Las vistas mantienen jerarquía móvil, controles con labels, estados vacíos y alternativa tabular cuando el mapa no carga.
