# Mortalidad pediátrica y números pequeños

RC3 usa defunciones de residentes de ISTAC `E30417A_000001`, grandes grupos CIE-10 y edades originales `<1`, `1–4`, `5–14`. Para cada isla suma una ventana fija 2020–2024. No mezcla `15–24` con adolescencia pediátrica.

Los conteos 1–4 quedan suprimidos y vacíos; el cero observado se conserva. La UI muestra “suprimido” y nunca cero. La supresión se aplica también antes de sumar edades para una tarjeta insular. No se publican tasas hasta incorporar denominadores anuales compatibles. Las ventanas reducen inestabilidad, pero no eliminan el sesgo de números pequeños.
